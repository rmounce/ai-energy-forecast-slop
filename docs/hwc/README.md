# Heat-pump hot water (HWC) — index

Scheduling and control of the Aquatech RAPID X6 HPWH against Amber import prices, separately
from the home battery. Live pipeline: `services/hwc_daemon.py` (replan + actuation) →
`hwc_dp_planner.py` (on/off optimisation) → `hwc_planner.py` (thermal/power model + publish) →
`hwc_executor.py` (device commands), with cycle telemetry in a local SQLite store
(`hwc_cycle_store.py` + `hwc_cycle_reporter.py`).

## Current state (2026-07-02)

- **Optimiser:** DP planner is default and only optimiser (`hwc.planner: "dp"`); heuristic
  block planner removed 2026-06-24; EMHASS retained as fallback.
- **Model:** single-temperature forward model with a continuous heat-rate taper
  (`hwc_planner._heat_rate_c_per_hour`); the two-state `(V_hot, T_hot)` model is shelved
  behind `hwc.dp_planner.soc_model` (off).
- **Telemetry:** cycles recorded live to SQLite; COP analysis reads the store.
